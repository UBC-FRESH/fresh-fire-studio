# P179.18 evidence-bounded suppression ensemble

Status: implemented prototype. No field campaign, no operational claim, no new
credentials.

## Purpose

Build a defensible research instrument from published evidence and open data.
The question is not “what is the true suppression effect?” It is:

> Given the published evidence and its uncertainty, what range of fire outcomes
> does this model produce, and which assumptions dominate?

This replaces the failed pattern of adding more mission geometry and hoping a
single point estimate becomes containment.

## Evidence base

### Wheatley 2024, Chapter 5

- ROS reduction: mean **0.5 m/min**, SD **0.7**
- fireline-intensity reduction: mean **72 kW/m**, SD **159**
- suppression hold: mean **123 s**, SD **117**
- high-water hold: **187 s**
- indirect high-water hold: **243 s**
- direct water depths: **1.4–2.3 mm**
- indirect water depths: **0.7–1.1 mm**

### McFayden et al. 2023

- effective aerial drop hold: **60 min**
- effective drop depth contours and breach criteria
- operational intensity discussion up to **10,000 kW/m**

### Van Wagner & Taylor 2022

- theoretical water depth from fireline intensity, fuel load and wetting.

### Existing open model inputs

- CFSDS `2003_526` fuel, terrain and observed perimeters;
- Open-Meteo/FireSTARR weather fixture;
- public VRI/SRTM scenes already in the studio.

## Design

### 1. Parameter distributions

Create `suppression/uncertainty.py`:

- `EvidenceRange`: mean, SD, lower/upper bounds, sampling method.
- `EvidenceSample`: ROS reduction, hold time, water depth, canopy penetration,
  required depth.
- truncated-normal sampling with a fixed seed;
- deterministic Latin-hypercube option for small ensembles.

### 2. Scenario projection

- `apply_sample_to_scenario(scenario, sample)` updates every drop’s:
  - `coverage_l_m2`;
  - `effect_duration_min`;
  - `canopy_penetration`.
- The suppression line/drop geometry is held fixed within an ensemble so the
  output measures **effect uncertainty**, not placement uncertainty.

### 3. Native ensemble runner

Create `scripts/evidence_ensemble_2003_526.py`:

- build the native grid once;
- run a free-burn baseline;
- run N samples through the same native growth kernel;
- use absolute ROS reduction from the sampled evidence;
- aggregate final area, IoU, area change and containment probability.

### 4. Summary

For each ensemble:

- mean, median, standard deviation;
- 5th and 95th percentiles;
- probability of any area reduction;
- probability of reducing area below the free-burn case;
- rank correlation between each parameter and final area.

### 5. Model card

Add `docs/p179-18-model-card.md`:

- what is observed, synthetic, published and uncertain;
- what the ensemble can and cannot answer;
- no operational use;
- known failure modes;
- how to reproduce.

## Implementation sequence

1. `suppression/uncertainty.py` + unit tests.
2. Scenario projection tests.
3. Ensemble runner with 32 samples on a fixed drop-line scenario.
4. Summary artifact and docs.
5. Update the suppression plan and README.
6. Commit.

## Acceptance criteria

- fixed seed reproduces the same samples;
- samples stay inside declared bounds;
- scenario projection changes only the three intended drop fields;
- ensemble artifact contains per-sample parameters and outcomes;
- summary reports percentiles and containment probability;
- all tests pass;
- docs state “evidence-bounded diagnostic”, not “validated operational model”.

## Non-goals

- No new field data collection.
- No operational dispatch recommendation.
- No claim that the mean published effect transfers to `2003_526` or BC.
- No 3D operational animation yet.

## Interpretation rule

A zero containment probability is a **model result**, not proof that aerial
suppression cannot work. It means the current evidence, geometry, hold time and
100 m model do not produce containment in this scenario.
